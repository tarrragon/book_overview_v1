### 模組結構（Phase 3a 策略，PM 前台規劃）

`.claude/skills/continuous-learning/scripts/memory_upgrade.py`：核心純函式（可 import 測試）+ 薄 CLI wrapper（`promote` / `scan` 兩子命令），沿用 allocator 的「純函式 + sys.path 借用」模式。

**依賴重用**（禁複製）：
- allocator：`sys.path` 借入 `.claude/skills/error-pattern/lib/allocator.py`，用 `allocate_pattern_id` / `identify_project_code`
- ID regex：`.claude/lib/pattern_id.py` 的 `PATTERN_ID_RE`（SSOT，dangling 掃描與 allocator 共用）
- frontmatter 解析：`yaml.safe_load`（hooks env 已含 pyyaml）

### 函式契約（RED 測試以此為 SSOT）

| 函式 | 簽名 | 行為 |
|------|------|------|
| `classify_memory` | `(memory_file: Path) -> str` | 解析 frontmatter：無 `upgrade` 鍵→`"unevaluated"`；`upgrade: deferred`→`"deferred"`；已標註升級（頂部 `> **Status**: Upgraded` 或 frontmatter `upgrade: done`）→`"upgraded"` |
| `find_dangling_pointers` | `(memory_file, error_patterns_dir) -> list[str]` | 抓內文所有 `PATTERN_ID_RE` 前綴號（`<CAT>-<PROJ>-NNN`），回傳在 `error_patterns_dir` 下無對應檔者（去重、排序） |
| `scan_memory_dir` | `(memory_dir, error_patterns_dir) -> dict` | 掃 `feedback_*.md`，回傳 `{"unevaluated": [...], "deferred": [...], "dangling": [{"file":..., "ids":[...]}]}`（值為檔名） |
| `annotate_upgraded` | `(memory_file, dest_path: str, date: str) -> None` | frontmatter `---` 結束後插入三行：`> **Status**: Upgraded — 已升級至框架共用層` / `> **Upgraded To**: \`{dest_path}\`` / `> **Upgraded Date**: {date}`（格式對齊 upgrade-decision-tree.md:186；已標註則不重複插入） |
| `prune_memory_index` | `(index_file, memory_filename: str) -> bool` | 移除 MEMORY.md 中 `](memory_filename)` 的索引行，回傳是否移除（找不到回 False，不報錯） |
| `promote_memory` | `(memory_file, category, claude_dir, project_code, dest_title, date, memory_dir) -> dict` | 一步：`allocate_pattern_id` 取 ID → 建 `error-patterns/<cat-dir>/<ID>-<slug>.md`（骨架 frontmatter + memory 內容轉入，供 agent 後續精修）→ `annotate_upgraded` 標註原檔 → `prune_memory_index` 修剪 MEMORY.md；回傳 `{"pattern_id":..., "dest_path":..., "index_pruned": bool}` |

### CLI 契約

- `scan [--memory-dir PATH] [--json]`：印三類清單（人讀）或 JSON
- `promote <memory_file> --category <CAT> --title <dest_title> [--date YYYY-MM-DD]`：執行 `promote_memory`，印 `pattern_id` 與 `dest_path`

### 測試

`.claude/hooks/tests/test_memory_upgrade_tools.py`（樣板同 `test_error_pattern_allocator.py`：`tmp_path` + `sys.path.insert` 引入 scripts）。RED 測試已由 PM 前台寫入（Phase 2），thyme 只需實作 GREEN 使其通過。

### 邊界與陷阱

- dangling 掃描的 `PATTERN_ID_RE` 只認前綴號（`<CAT>-<PROJ>-NNN`），flat base（`PC-099`）本就在 error-patterns/ 存在，不誤報
- `annotate_upgraded` 冪等（重入不重複插標註）
- `prune_memory_index` 對缺行 graceful（回 False 非 raise），對齊 observability 規則
- PC-135：scripts 若獨立 pep723 執行需宣告 pyyaml；本票測試借 hooks env（已含 pyyaml），CLI 若加 shebang 須帶 `dependencies = ["pyyaml"]`
