**promote `<memory_file> --category <CAT> [--dest <path>] [--reason ...]`**：一步完成
1. allocator 分配 `<CAT>-<PROJ>-NNN`；建 error-pattern 檔於對應 category 目錄（內容由 memory 轉寫，人工/agent 提供 dest 語意）
2. 原 memory 檔頂部插入三行標註（Status/Upgraded To/Upgraded Date），格式精確對齊 decision-tree.md:186

**scan**：輸出三類清單
- 未評估：`feedback_*.md` frontmatter 無 `upgrade:` 鍵
- deferred：frontmatter `upgrade: deferred`
- dangling pointer：memory 內文引用的 `PC/IMP/ARCH-<PROJ>-NNN` 在 error-patterns/ 不存在（lineage 重編號場景）

**version-release 稽核接線**：新增 check 掃 memory 升級狀態，輸出分流遵循率（已標註/未評估比例）；稽核輸出作為「是否建強制層 hook」的決策 trigger（decision-trigger-binding 規則 2）。
