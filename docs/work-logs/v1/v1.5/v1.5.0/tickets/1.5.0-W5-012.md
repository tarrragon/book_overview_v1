## Problem Analysis
### 問題根因

48 個 skill 採 SKILL.md 大寫慣例，4 個歷史檔為小寫 skill.md。macOS 大小寫不敏感檔案系統上慣例混雜，使工具層與 git pathspec 判定不一致（IMP-V1-006 實證 commit 失敗一次）。

### 影響範圍

- `.claude/skills/continuous-learning/skill.md`
- `.claude/skills/error-pattern/skill.md`
- `.claude/skills/security-review/skill.md`
- `.claude/skills/strategic-compact/skill.md`
- 4 處框架引用（pm-quality-baseline.md / tdd-collaboration-flow.md / three-phase-reflection-methodology.md / allocator.py）

### 相關 Error Pattern

IMP-V1-006（大小寫不敏感檔案系統上的命名慣例不一致）

## Solution
### 執行方式

macOS 大小寫不敏感檔案系統，採兩段式 git mv：

1. `git mv skill.md skill.md.tmp`（4 檔）
2. `git mv skill.md.tmp SKILL.md`（4 檔）

### 引用同步

grep 掃描 `.claude/` 全目錄，發現 4 處引用並同步更新：

| 檔案 | 引用內容 |
|------|---------|
| `.claude/pm-rules/pm-quality-baseline.md` | continuous-learning/skill.md → SKILL.md |
| `.claude/methodologies/tdd-collaboration-flow.md` | continuous-learning/skill.md → SKILL.md |
| `.claude/methodologies/three-phase-reflection-methodology.md` | continuous-learning/skill.md → SKILL.md |
| `.claude/skills/error-pattern/lib/allocator.py` | error-pattern/skill.md → SKILL.md |

settings.json 無引用（已確認）。
