## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->
### 問題根因

W6-001 建立的守護鏈為單向：popup-style-scope.test.js（C1/S2 案例）驗證 popup.html 不再含已遷移選擇器的內嵌規則，但依賴 tests/unit/helpers/popup-migrated-selectors.js 的 MIGRATED_SELECTORS 手動清單。component-rules.js 新增規則而 helper 未同步時，測試全綠靜默漏網（Phase 4 T2 裁定真實輕債）。

### 影響範圍（PM 前置驗證 2026-07-12）

- `src/core/design-system/component-rules.js`（231 行）：L24 `const COMPONENT_RULES = \``——**CSS template literal 字串**，L231 `module.exports = { COMPONENT_RULES }`。斷言需以 regex 從 CSS 字串解析頂層選擇器集合。
- `tests/unit/helpers/popup-migrated-selectors.js`（70 行）：L15 `MIGRATED_SELECTORS` 陣列，L70 匯出 `{ MIGRATED_SELECTORS, EXEMPT_SELECTORS }`。
- `tests/unit/popup-style-scope.test.js`（85 行）：既有 describe「popup.html 內嵌 style 收斂（1.5.0-W6-001）」（L63），新案例加入此檔或同檔新 describe。
- 無 src 變更，純測試補強。

### 簡化 WRAP 三問

- W：候選 (a) 測試內 regex 解析 CSS 字串斷言全等（採用，how.strategy 既定，零 src 變更）；(b) component-rules.js 改匯出結構化選擇器清單供測試直讀（改 src，超出本票「純測試補強」邊界，若 (a) 實作中發現 regex 脆弱可 spawn-request 提案）。
- A：機會成本低——單檔測試補強不擠壓 W6 其他票。
- P：最可能失敗＝regex 解析與 CSS 字串邊界不符（巢狀 @media、逗號複合選擇器、偽類）致集合比對假紅/假綠。防護：acceptance 2 強制人為漂移實驗（加規則不同步 helper 必紅，實驗後還原）。

### 相關 Error Pattern

無直接對應。EXEMPT_SELECTORS 語意（豁免清單是否參與全等比對）由執行代理人依 helper 內註解裁定並記錄於 Solution。

## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
### 實作內容（general-purpose，2026-07-12）

**方案**：採 Problem Analysis WRAP 候選 (a)——測試內解析 COMPONENT_RULES CSS 字串斷言集合全等，零 src 變更。

1. `tests/unit/helpers/popup-migrated-selectors.js`：新增並匯出 `parseTopLevelSelectors(cssText)`（剝除 CSS 註解 + 大括號深度掃描，深度 0 遇 `{` 前文字即 top-level 選擇器，@keyframes 計一項、內層 0%/100% 不計）。解析器放 helper 供兩端共用，避免兩份平行解析實作漂移。
2. `tests/unit/popup-style-scope.test.js`：
   - 原檔內 HTML 解析函式改為 `parseInlineStyleSelectors(html)` 薄包裝（擷取 `<style>` 區塊後委派 helper 解析器），S1/S2 語意不變。
   - 新增 describe「COMPONENT_RULES 與 MIGRATED_SELECTORS 雙向守護（1.5.0-W6-011）」B1 案例：`parseTopLevelSelectors(COMPONENT_RULES)` 排序後 `toEqual` 排序後 `MIGRATED_SELECTORS`，任一端漂移即紅燈且 diff 直接列出漂移選擇器。

**EXEMPT_SELECTORS 裁定**：不參與全等比對。依 helper 內註解「popup.html `<style>` 豁免保留清單（頁面專屬佈局，非共用元件）」，其成員（body/.header/.header h1/.header p/.content/.version）設計上永不遷入 COMPONENT_RULES，故 B1 全等對象僅 MIGRATED_SELECTORS；EXEMPT_SELECTORS 由既有 S1 完全相等斷言獨立守護。

**regex 脆弱性風險（WRAP P 預想）**：未發生。COMPONENT_RULES 無巢狀 @media；逗號複合選擇器（如 `.progress-header, .results-header, .error-header`）以整行字面計一項，與 MIGRATED_SELECTORS 字面條目一致；@keyframes 深度掃描正確計一項。人為漂移實驗（acceptance 2）證明無假綠。
