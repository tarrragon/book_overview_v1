### 問題根因

枚舉驗證閘（W5-005.1.2）以 warn 模式上線，需量測誤報率決定是否切換 deny。

### 影響範圍

- `.claude/skills/ticket/ticket_system/constants.py` — `ENUM_GATE_MODE = "warn"`
- `.claude/hook-logs/enum-gate.log` — 違規日誌（預期為量測資料源）

### 相關 Error Pattern

- W5-005 F3「無 kernel：寫入路徑未收斂」為根因
- PC-MON-002「必填不等於有效」為上游同病

### 方法

WRAP 簡化三問：
- W（Widen）：(A) 量測 0 即切 deny (B) 延長觀測至一週再決定 (C) 不切 deny，只維持 warn 永久。選 A——14h 涵蓋全生命週期路徑且 0 違規，延長觀測不增加資訊量。
- A（Attain distance）：本票 P2 且為 .1 收尾最後一步，機會成本低。
- P（Prepare to be wrong）：最可能風險 = 有某種合法操作路徑未被 14h 覆蓋到（如 migrate/batch-create），deny 後才炸。防護：deny 模式仍保留 stderr 完整訊息，修復只需加白名單一行。
