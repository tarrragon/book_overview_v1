## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
根因：sync-pull commit 44867ca43（upstream v2.3.0）將 `.claude/hooks/hook_utils/` package 內容遷移至 `.claude/lib/`（hook_io.py/hook_logging.py 合併擴充、hook_base.py/hook_ticket.py 移動），舊 `hook_utils/` 目錄僅殘留 __pycache__（namespace package，`__file__` 為 None，故 ImportError 訊息顯示 unknown location）。`main-thread-edit-restriction-hook.py:31` 仍用舊 `from hook_utils import ...`，同檔案其他行早已改用 `from lib.xxx import ...`（遷移未同步全檔）。

修復：第 31 行 `from hook_utils import ...` 改為 `from lib import ...`（`.claude/lib/__init__.py` 已 re-export 全部 7 個符號：setup_hook_logging/run_hook_safely/get_project_root/save_check_log/read_json_from_stdin/is_subagent_environment/emit_hook_output）。零 runtime 邏輯變更，僅修 import 路徑。

已 grep 確認 `.claude/hooks/*.py` 與 `tests/*.py` 無其他 `from hook_utils import` 實際引用（僅 2 處註解文字提及）。
