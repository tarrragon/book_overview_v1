### Context Bundle

**目標**：新增 `spawn_request_checker.py`，在 complete 時掃描 Spawn Requests 章節偵測未處理條目。

**Spawn Request 條目格式**（由 `add-spawn-request` CLI 生成，見 `track_acceptance.py:913-921`）：
```
- **SR-N** (timestamp)
  - what: ...
  - why: ...
  - suggested_type: ...
  - suggested_priority: ...
  - related_files: ...
  - context: ...
  - status: pending
```
status 有效值：`pending`（未處理）、`processed`（已建 ticket）、`dismissed`（已評估不需要）。

**現有 checker 模式參考**：`acceptance_checkers/multi_view_checker.py` 或 `ana_spawn_consistency_checker.py`。
每個 checker 匯出一個 `check_*` 函式，回傳 `(should_warn: bool, msg: Optional[str])`。

**整合點**：`acceptance_checker.py` 為主入口，呼叫各 checker 並彙整結果。

**WARNING 行為**：偵測到 `status: pending` 的 SR 條目時發 WARNING（不硬擋），列出未處理編號。PM 可 --force 旁路。

**Commit policy**：單一 commit 含實作 + 測試
