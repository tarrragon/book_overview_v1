## Problem Analysis
<!-- Schema[ANA/Problem Analysis]: 必填（.claude/pm-rules/ticket-body-schema.md） -->
### 問題根因

hook WARNING 訊息列出合法值和子欄位要求，但未展示正確寫入格式範例。LLM 看到「skipped 需附 reason」後直覺寫成 heading 結構：

```markdown
### multi_view_status    ← LLM 自然傾向
status: skipped
reason: ...
```

而 hook \_parse\_field 用 regex \`^\\s\*multi\_view\_status\\s\*:\\s\*(.+?)\\s\*\$\` 搜尋，期望 flat key-value：

```markdown
multi_view_status: skipped
reason: ...
```

### 影響範圍

- \`.claude/hooks/acceptance\_checkers/multi\_view\_checker.py\` 的 \_format\_missing\_warning 函式

### 相關 Error Pattern

- opinionated-default-design 原則：「預設行為 > 文件規範」——WARNING 訊息是 LLM 的即時引導，應展示格式範例
