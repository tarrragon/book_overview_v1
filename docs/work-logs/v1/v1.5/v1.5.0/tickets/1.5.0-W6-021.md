### 問題根因

全套 41 個 skipped 測試集中於兩個整檔 describe.skip 套件，長期 skip 使紅燈防護對兩個模組（頁面偵測 utils、錯誤恢復工作流）失效。兩套件成因不同：

- **error-recovery-workflow.test.js**：ErrorSimulator 與測試預期契約不符（拋出式 vs 優雅攔截），原追蹤票 0.15.0-W1-002 已完成但未解決此項，追蹤鏈斷裂形成無人認領的死角。

### 分析目標

git 史/註解/引用票考證兩套件 skip 起點與現況有效性，各產出三選一決策（恢復啟用/改寫/正式豁免）並落地為 ticket 或豁免記錄。
