### 1. Token 層（shadows.js + generator + manifest）

新增 `src/core/design-system/shadows.js` `DIVIDER_COLORS`（subtle/normal/strong，rgba(33,150,243) alpha 0.06/0.10/0.14，與 APP `UIColors.dividerSubtle/Normal/Strong` 同值）。`scripts/generate-design-system-css.js` 引入並產出 `--divider-subtle/normal/strong` CSS 變數（offset/blur 隨變體不同，故僅收斂顏色維度，沿用既有 SHADOW_COLORS 設計慣例）。`token-manifest.json` 三筆 divider 條目由 `platformOnlyApp`（v1:null）改為 `shared`（base=值，v1.path=`DIVIDER_COLORS.subtle/normal/strong`）；同步更新 `inventorySummary.byCategory`（shared 32→35、platformOnlyApp 52→49）、`byDomain.colors`（shared 5→8、platformOnlyApp 12→9）、`matchedPairAnalysis`（allDomains 49→52 / 34.69%→45.61%，colorsdomainOnly 20→23 / 75.00%→60.53%）、`categoryEnum.platformOnlyApp` 說明文字。`node scripts/validate-token-manifest.js` 雙向校驗通過（65 項正向 / 65 項反向，0 errors）。

### 2. createDivider 工廠 + CSS 元件規則

`src/core/ui/components/ui-factory.js` 新增 `createDivider({ variant })`（subtle/normal/strong 白名單驗證，缺省/無效值 throw），命名與 API 對齊 APP `AppDivider.subtle/.normal/.strong`（spec §14.6 契約）。`src/core/design-system/component-rules.js` 新增 `.divider` / `.divider-subtle` / `.divider-normal` / `.divider-strong` 四條規則，以 `box-shadow`（非 border）呈現分割陰影，offset/blur 對齊 APP spec §8.2（0 1px 2px / 0 2px 4px / 0 3px 6px）。因 divider 為新元件（非 popup.html 遷移），`tests/unit/helpers/popup-migrated-selectors.js` MIGRATED_SELECTORS 補 4 條選擇器以滿足 B1 COMPONENT_RULES↔MIGRATED_SELECTORS 全等雙向守護（1.5.0-W6-011）。
