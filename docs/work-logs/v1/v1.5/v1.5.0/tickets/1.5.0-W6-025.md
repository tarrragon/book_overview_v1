### 等效性比對結論

逐一比對三檔 describe block：網域檢測 / 頁面類型識別 / 可提取性檢查 / 頁面準備狀態 / URL 路徑分析 / 整合功能 / 快取機制 / 錯誤處理，simple 版每一類別的斷言涵蓋範圍均 >= legacy 版（含相同或更多測資）。

差異點：legacy 對 `isReadmooDomain(undefined)` 額外測了「當前 URL 為非 Readmoo 時回傳 false」分支；該分支程式碼路徑（page-detection-utils.js:44-48）與 simple 版已測的「當前 URL 為 Readmoo 時回傳 true」分支共用同一段邏輯（僅 mock URL 不同），無獨有程式碼路徑未覆蓋，判定等效，未遷移獨立斷言。

測試計數：legacy 29、simple 29（與註解宣稱 29:29 一致）。
