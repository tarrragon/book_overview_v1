### 斷言級 diff 比對結果

legacy（29 test）vs simple（29 test）逐條比對 test name + 斷言內容：

- 完全一致（重疊）：27 條
- legacy 獨有斷言（已遷移至 simple）：
  1. `isReadmooDomain('https://readmoo.com')`（無 path 的裸網域）— 原 legacy 併入「主網域」測試，simple 版「網域檢測」測試漏收此案例
  2. `isReadmooDomain(undefined)` 的 false 分支（切換 mock location 至非 Readmoo 後呼叫無參數版本）— simple 版「應該使用當前頁面 URL 作為預設值」僅測 true 分支
- simple 獨有（非等效性缺口，屬額外覆蓋，不影響刪除判斷）：
  - 「應該提供快取統計資訊」`getCacheStats()`
  - 「應該處理各種錯誤輸入」整合型邊界測試

遷移動作：於 `page-detection-utils-simple.test.js`「網域檢測功能」describe 補上述 2 條斷言（新增 1 條獨立 test「應該處理 undefined 參數使用當前 URL」+ 既有網域測試補一行斷言），確保與 legacy 完全等效覆蓋後再刪除 legacy 檔。

決策：**保留**，非死碼、無 skip 問題，與 legacy 刪除無關聯。
