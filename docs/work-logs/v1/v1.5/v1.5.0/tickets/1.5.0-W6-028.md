## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->
### 問題根因

APP 端對帳（0.38.0-W10-004）發現 token-manifest.json 兩處差異：

1. **onBackground 幻影 alias path（line 104）**：`app.path` 宣稱 `UIColors.onBackground (alias of onBackgroundLight)`，但 Dart 檔案實際無 `onBackground` getter，僅有 `onBackgroundLight`。
2. **borderLight 條目遺漏**：`border` 條目 notes 提及「僅存 @Deprecated borderLight/borderDark 供相容」，但只有 `borderDark`（line 120-122）有獨立條目，`borderLight` 漏建。

### 影響範圍

- `src/core/design-system/token-manifest.json`（唯一修改檔案）

### Context Bundle

**修正 1 — onBackground app.path（line 104）**

修改前：`"path": "UIColors.onBackground (alias of onBackgroundLight)"`
修改後：`"path": "UIColors.onBackgroundLight"`

**修正 2 — 補建 borderLight 條目**

在 `borderDark` 條目（line 122）之後插入新條目：
- key: `borderLight`
- category: `platformOnlyApp`（V1 無 borderLight，rg 確認 colors.js 僅有 borderDark）
- base: null
- platforms: { v1: null, app: { path: "UIColors.borderLight", value: "#BDBDBD", appDeprecated: true } }
- notes: "APP 側已標記 @Deprecated（平面化設計不使用邊框），僅存相容值"

**修正 3 — inventorySummary 計數同步**

- `totalTokens`: 114 → 115
- `byCategory.platformOnlyApp.count`: 49 → 50
- `byCategory.platformOnlyApp.percentage`: 重新計算（50/115 = 43.48%）
- 其他三個 category percentage 也需重算分母 115
- `byDomain.colors.total`: 38 → 39
- `byDomain.colors.platformOnlyApp`: 9 → 10
- `matchedPairAnalysis` 分母更新（allDomains matched pair 不變，但 total 115 影響 calibratedRatio 計算）

**修正後驗證**：`npm run validate:token-manifest`

**Commit policy**：單一 commit，訊息格式 `fix(1.5.0-W6-028): 修正 token-manifest onBackground path + 補建 borderLight 條目`
