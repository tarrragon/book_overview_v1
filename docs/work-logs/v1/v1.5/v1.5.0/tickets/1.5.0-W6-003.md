### WRAP 三問（認領 Checkpoint）

- **W（其他做法）**：(a) 直接重命名既有 variant 對齊契約——棄，違反契約規則「v1 既有 primary/secondary/danger 保留為別名」且破壞 4 個 popup 引用點；(b) 新增契約語意名 + 既有名保留——採，契約明文規定。
- **A（機會成本）**：本票是 W6-005（測試同步）的邏輯前置，先做可減少 W6-005 重工；不擠壓其他 W6 票。
- **P（最可能失敗）**：token 主名差異（V1 success/warning vs APP positive/negative）處理過頭——誤把 token 重命名納入本票。防護：token 值層/主名統一屬 W6-006（PROP-014 評估）與 W6-007（token manifest）範圍，本票僅比對元件引用並記錄差異，禁止重命名 design-system token 主名。

- **Out**：divider 元件（W6-004）、新元件測試補充（W6-005）、card raised/inset/engraved 與 dialog/badge/input 新建（契約標 v1 待建）、token 主名重命名（W6-006/W6-007）。若判定待建元件 1.5.0 內缺票，用 add-spawn-request 上報，不自行擴 scope。
## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
依 design-system-spec.md §14.6 契約總表對齊 ui-factory.js 元件命名，Scope 邊界內容如下：

**createButton variant**：BUTTON_VARIANTS 補 `confirm`（token positive，v1 沿用既有 `--color-success`，對映 APP AppButton.confirm）與 `ghost`（token transparent，背景透明 + `--color-primary` 文字，對映 AppButton.ghost）。既有 primary/secondary/danger 依契約規則「v1 既有保留為別名」不動。component-rules.js 新增 `.button.confirm`/`.button.confirm:hover`/`.button.ghost`/`.button.ghost:hover` 規則，值一律引用 var(--*) token。

**createButton size**：BUTTON_SIZES 補 `medium`/`large`；`normal` 保留為既有呼叫點（popup.js 等）相容別名，映射為 medium 視覺（沿用 `.button` 基準樣式，無額外 class）。component-rules.js 新增 `.button.large` 規則（padding/font-size 加大）。

**逐項比對結果**：
- 按鈕 5 variant 契約項全數對齊（primary/confirm/danger/secondary/ghost）。
- 卡片 default/error 為 V1 現況特有值，契約表無對應列，記錄差異不修改（屬既有 status-card 兩級卡片權重設計，非契約範疇）。
- 卡片 raised/inset/engraved、對話框、標籤、分隔、輸入框皆為契約標「v1 待建」，超出本票 In Scope（分屬 W6-004/後續票），依規則用 add-spawn-request 上報缺票議題，不擴 scope。
- token 主名差異（V1 success/warning vs APP positive/negative）僅記錄不重命名，維持既有 colors.js 主名（屬 W6-006/W6-007 範疇）。

**同步修正**：tests/unit/helpers/popup-migrated-selectors.js 的 MIGRATED_SELECTORS 補 5 個新選擇器（`.button.confirm`/`.button.confirm:hover`/`.button.ghost`/`.button.ghost:hover`/`.button.large`），維持與 popup-style-scope.test.js 雙向守護一致；ui-factory.test.js 新增 confirm/ghost/large 3 組單元測試。

**重生成產物**：`node scripts/generate-design-system-css.js` 重新產生 design-system.css（AUTO-GENERATED，不手改）。
