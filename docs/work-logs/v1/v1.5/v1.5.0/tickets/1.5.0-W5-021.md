### Context Bundle

**架構分析**：

- 現有 set-* 子命令在 `track.py` 註冊（:651+），實作在 `fields.py`
- `append-log` 實作在 `track_acceptance.py`，可作為寫入 body section 的參考
- 新命令需：(1) 新建 `track_structured_body.py`（2) 在 `track.py` 註冊子命令（3) 新建測試

**Exit Status schema**（來自 W17-010）：
- exit_status: success|needs_context|blocked|partial_success|failed
- reason: str
- confidence: 0.0-1.0
- acceptance_met: list[int]
- acceptance_unmet: list[int]
- artifacts: list[str]

**Completion Info schema**：
- agent: str（執行代理人名稱）
- review-status: pending|reviewed|n/a
- summary: str（變更摘要）

**實作策略**：
1. 新建 `track_structured_body.py` 含 `execute_set_exit_status` 和 `execute_set_completion_info`
2. 使用 `append-log` 底層寫入邏輯（body section replacement）
3. 在 `track.py` 註冊 `set-exit-status` 和 `set-completion-info`
4. 新建 `tests/test_structured_body.py`

**Commit policy**：單一 commit 含實作 + 測試

## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
新增 track_structured_body.py 提供 execute_set_exit_status / execute_set_completion_info，兩者組出符合 schema 的內容後委派 execute_append_log（track_acceptance.py）完成實際寫入（沿用 file_lock/precondition/placeholder 替換/dedupe/auto-commit）。在 track.py 註冊 set-exit-status（--status/--reason/--confidence/--acceptance-met/--acceptance-unmet/--artifacts）與 set-completion-info（--agent/--review-status/--summary）兩子命令，並驗證枚舉值與 confidence 範圍。
