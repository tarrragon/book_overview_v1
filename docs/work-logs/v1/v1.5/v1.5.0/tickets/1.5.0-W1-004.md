## Solution
<!-- Schema[ANA/Solution]: 必填（.claude/pm-rules/ticket-body-schema.md） -->
### 調查結論

博客來電子書庫（viewer-ebook.books.com.tw）結構調查完成，關鍵發現：

1. **資料來源為 REST API**（非 DOM 解析）：`appapi-ebook.books.com.tw/V1.7/CMSAPIApp/ReadList` POST 回傳 JSON，含 49 個欄位
2. **技術架構**：jQuery 3.7.1 MPA（非 SPA），無需處理 hash routing
3. **認證機制**：跨域 OAuth（cart.books.com.tw → viewer-ebook.books.com.tw）
4. **分頁機制**：offset-based，每頁 40 筆，「看更多」按鈕觸發
5. **與 Readmoo 差異**：API 提供作者欄位（Readmoo DOM 無）、分頁按鈕（非虛擬 scroll）

完整報告：docs/bookstores/books-com-tw.md v2.0.0
