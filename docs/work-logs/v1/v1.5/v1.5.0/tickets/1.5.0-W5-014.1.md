### 設計方向

**務實方案**：Stop hook 在 session 結束時檢查 confabulation 常見副作用指標，而非嘗試解析 transcript 找宣稱（transcript 解析成本高且脆弱）。

**指標設計**（confabulation 副作用的可觀測指標）：

| 指標 | 偵測什麼 | 命令 |
|------|---------|------|
| 1. 髒工作區 | 宣稱 commit 但未實際 commit | `git status --porcelain` |
| 2. in_progress ticket 未收尾 | 宣稱 complete 但未實際 complete | `ticket track list --status in_progress --format ids` |
| 3. 最近 commit 時間戳 gap | session 有工作但無 commit（可能全虛構） | `git log --since` vs session 長度 |

指標 1-2 是 confabulation 最常見的可觀測副作用（PC-166 案例：宣稱 commit 但 git log 無 hash、宣稱 complete 但 ticket 仍 in_progress）。

### 實作內容

Stop hook `.claude/hooks/confabulation-audit-hook.py`，session 結束時檢查三項指標：
