### 需從原文提取並中文化的要素

1. **context 充足度閘門**：三問門檻（分析對象是什麼 / 影響誰或給誰 / 成功長什麼樣），資訊不足時一次一問補齊；先掃現有 context（對話 / CLAUDE.md / memory/）再問。
2. **raw 失敗原因列舉**：單次完整分析，無預設分類；每原因 1-2 句、具體、錨定計畫真實細節、真實威脅（非湊數）；數量隨計畫而定（3–9 不等）。
3. **並行深挖（每原因一個 subagent）**：原文 prompt 範本（líneas 107-132）產出三要素——(a) 失敗故事 2-3 段敘事、(b) 底層假設一句話、(c) 1-2 個可觀測早期警訊；單 agent 回應 < 300 字、直白不粉飾。
4. **三分綜合報告**：最可能失敗 / 最危險失敗 / 隱藏假設 / 修訂計畫（每項對應一個失敗場景、具體可本週執行）/ pre-launch checklist（3-5 項）。
