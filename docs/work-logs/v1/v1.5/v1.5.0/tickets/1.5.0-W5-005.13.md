### 修復方案

`.claude/skills/ticket/ticket_system/commands/create.py` `execute()`：以 `is_child = bool(args.parent)` 分流。

- **子任務（`is_child=True`）**：version 完全繼承父票——優先以 `extract_version_from_ticket_id(args.parent)` 解析（父票版本為唯一權威來源），僅當 `--parent` 格式異常無法解析時才 fallback 至 `resolve_version(args.version)`。完全跳過版本歸屬引導（`suggest_version_for_ticket`）與 `validate_version_registered` 註冊檢查。wave 承接既有邏輯（`_resolve_ticket_id_and_wave` 內 `extract_wave_from_ticket_id(args.parent)`），本次未變動。
- **根票（`is_child=False`）**：版本歸屬引導 + `VERSION_NOT_REGISTERED` 檢查邏輯與修復前完全一致（僅搬移至 else 分支，無行為變更）。
