## Solution

### 設計決策（2026-07-12）

**命名**：`dill-javascript-developer`。dill 為未占用香料名（roster 已用清單勾稽：parsley/fennel/thyme/basil/cinnamon/sage/saffron/pepper/oregano/ginger/mint/clove/coriander/bay/lavender/star-anise/sumac/sassafras/rosemary 皆迴避，tarragon 為用戶名不可用）。

**產出四項**：

| 產出 | 路徑 | 依據模板 |
|------|------|---------|
| Agent 定義 | `.claude/agents/dill-javascript-developer.md` | `language-agent-template.md`（三區塊標準：允許產出/禁止行為/適用情境） |
| 品質規則 | `.claude/references/quality-javascript.md` | `quality-language-template.md`（放 references/ 對齊 quality-python.md 既有位置，非模板所述 rules/core/） |
| Registry 註冊 | `.claude/agents/registry.yaml` | 對齊 parsley/fennel phase3b 條目格式，置於 fennel-go-developer 之後 |
| CLAUDE.md §4 | 實作代理人改為 dill-javascript-developer，移除 general-purpose 過渡標註 | Context Bundle 第 5 點 |

**Model 評估（acceptance 4，haiku vs 其他）**：採 **sonnet + effort: low**，非模板預設 haiku。理由：

1. **任務複雜度**：本專案 Extension 實作涉及跨組件通訊（SW/content/popup 三 context）、SW 事件監聽器頂層同步註冊時序、DOM 提取多層 fallback、CJS/ESM 雙模式相容——錯誤形態多為 runtime 靜默失效（PC-165 類），unit test 綠燈無法完全攔截，需要較強跨檔案因果推理，haiku 漏判風險高。
2. **前例一致性**：既有同級實作代理人 fennel-go-developer.md 與 thyme-python-developer.md 的 frontmatter 實際皆為 `model: sonnet` + `effort: low`（registry.yaml 內 haiku 為舊值未同步）；dill 對齊 md 實況並在 registry 條目直接寫 sonnet，避免再製造 md/registry 漂移。
3. **成本控制**：以 `effort: low` 取代降級模型，兼顧推理品質與 token 成本。

評估理由同步寫入 agent md frontmatter 後的「Model 選擇」blockquote（開檔即見）。

**quality-javascript.md 內容涵蓋（acceptance 2 對應）**：

- Chrome Extension 關鍵限制：第 5 節逐項正誤對照表（禁 require()/bare specifier/global、SW 無 window、Storage keys 陣列、事件監聽器頂層註冊、esbuild 三入口 bundle），自 chrome-extension-quickref.md 抽取並補正誤範例
- ES Module 慣例：第 6 節 CJS/ESM 雙模式（Jest CJS 載入 vs esbuild bundle）、globalThis 統一掛載
- Jest 慣例：第 7 節（jsdom 非真實 Chrome、Chrome API mock、performance.now mock、計時斷言禁令路由 test-assertion-design-rules、PC-165 綠燈邊界）
- 專案慣例：第 2 節常數集中管理（design-system / ui-text.js / layout.js / ui-factory.js，對齊 CLAUDE.md §6.1）、第 3 節 Messages 系統（GlobalMessages 3 條件 AND + 命名前綴規範，路由 docs/project-conventions.md）、第 4 節 ErrorCodes/OperationResult
- 版本規範：ES2022+（Chrome 114+ / Node.js 20+），第 8 節列 6 項版本特有語法對照（#私有欄位/at()/??/?./structuredClone/Error cause）+ 3 項禁止（var/callback 巢狀/top-level await 進 bundle），滿足模板「至少 3 項」要求

**設計取捨**：agent md 不搬品質檢查全文（hook 內容錯置啟發式防護），品質規則集中 quality-javascript.md 由 `@` 強制載入；agent md 僅留 H3 級流程內檢查清單，與模板結構一致。
