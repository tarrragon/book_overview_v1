## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
在 BooksComTwAdapter 新增 ReadList API 擷取路徑，`extractAllBooks()` 優先呼叫 `_fetchBooksFromApi()`（內部 `_requestReadListPage()` 以 offset/page_size 分頁循環，直到 `current_offset + page_size >= total_records` 或該頁 records 為空），並透過 `_mapApiRecordToBookData()` 將 `item_info` 對應為 BookSchemaV2 欄位（bookId/title/author/publisher/publishDate/coverUrl/readProgress/lastReadAt/purchaseDate/format/language/itemType/source）。

API 呼叫失敗（fetch 拋錯、回應非 ok、records 非陣列）時於 catch 區塊記錄 BOOKS_COM_TW_API_FETCH_FAILED warning 並降級呼叫 `_extractAllBooksFromDom()`——即原本的 DOM 解析路徑（checkPageReady + _loadAllPages + parseBookElement），邏輯完全未變動，僅重構抽出獨立私有方法供 fallback 呼叫。

chrome.storage.local 寫入由既有上層 book-data-extractor.js -> 訊息傳遞 -> background 通用管線負責（跨平台共用，非本 adapter 職責），故 acceptance 第 4 項已由既有架構滿足，未在本 ticket 新增程式碼。

## Context Bundle

### 目標

在 BooksComTwAdapter 中加入 API 路徑，讓 extractAllBooks 優先透過 ReadList API 取得完整 JSON 資料，DOM 解析保留作 fallback。

### 關鍵檔案

- src/content/adapters/books-com-tw-adapter.js — 主要修改目標
- docs/bookstores/books-com-tw.md — API 端點與欄位對照表（必讀）

### API 規格（摘錄自 books-com-tw.md）

- Endpoint: POST //appapi-ebook.books.com.tw/V1.7/CMSAPIApp/ReadList
- Request body: { offset: 0, page_size: 40, sort_order: "ReadTimeDesc", last_updated_time: "1900-01-01T00:00:00+08:00", eplanid: "all", is_buyout: "", listname: "[\"all\"]", cat: "all" }
- Response: { total_records, current_offset, updated_time, records: [{ book_uni_id, item_type, item_info: { item, c_title, author, publisher_name, publish_date, efile_cover_url, percent, last_read_time, auth_time, book_format, language, type, ... } }] }

### 實作策略

1. 新增 _fetchBooksFromApi() 私有方法，POST ReadList API 循環 offset 取全部書目
2. 修改 extractAllBooks() 為 try API first, catch 降級為既有 DOM 路徑
3. 新增 _mapApiRecordToBookData(record) 將 API item_info 對應為 BookSchemaV2 欄位
4. API 呼叫使用 fetch()（content script 同域 cookie 自動攜帶）
5. 保留既有 DOM 路徑完全不變（_loadAllPages + parseBookElement）作為 fallback

### 欄位對應表

| API item_info | BookSchemaV2 output |
|---------------|---------------------|
| item | bookId |
| c_title | title |
| author | author |
| publisher_name | publisher |
| publish_date | publishDate |
| efile_cover_url | coverUrl |
| percent | readProgress |
| last_read_time | lastReadAt |
| auth_time | purchaseDate |
| book_format | format |
| language | language |
| type | itemType |

### commit policy

- 直接 commit 到 feat/1.5.0-W4-004-books-com-tw-api-extract 分支
- commit message 前綴: feat(1.5.0-W4-004)

### 注意事項

- content script 跑在 viewer-ebook.books.com.tw 域名下，但 API 在 appapi-ebook.books.com.tw（跨域）。manifest.json host_permissions 已加 *://*.books.com.tw/*，但 content script 的 fetch 可能仍受 CORS 限制。若 CORS 阻擋，需改為透過 background service worker 代理 API 呼叫
- API response 的 listname 參數可能需要根據分類調整（目前用 ["all"]）
- 保留 source: 'books-com-tw' 欄位，與 DOM 路徑一致
