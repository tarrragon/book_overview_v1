## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->
### 問題根因

component-rules.js L175-180（`.progress-bar`）與 L182-187（`.progress-fill`）宣告逐字相同（height:100% / background:var(--color-primary) / border-radius:var(--radius-xs) / transition:width .3s）。pre-existing，W6-001 遷移時逐字搬運未改寫。

### 影響範圍（PM 前置驗證 2026-07-12）

- 兩 class 均活躍使用，**禁止刪除任一**：`.progress-bar` 為容器（popup-ui-components.js L173 querySelector、ui-progress-handler.js L418 等）；`.progress-fill` 為內層填充（popup.js L473 `progressBar.querySelector('.progress-fill')`、popup-ui-components.js L164）。清理方向為合併群組選擇器 `.progress-bar,\n.progress-fill { ... }`（渲染語意不變）或代理人分析後之等效方案。
- **與 W6-011 新守護的互動（關鍵）**：B1 案例（popup-style-scope.test.js）以 `parseTopLevelSelectors(COMPONENT_RULES)` 全等斷言 MIGRATED_SELECTORS。合併為逗號群組後解析結果取決於 helper 對群組選擇器的處理語意——實作前先讀 tests/unit/helpers/popup-migrated-selectors.js 的 `parseTopLevelSelectors`，必要時同步 helper/清單（此為 B1 守護設計內行為，同步變更需記入 Solution）。

### 簡化 WRAP 三問

- W：(a) 合併群組選擇器（採用方向，保留兩 class）；(b) 刪其一並改 DOM/JS（越界——src 變更限 component-rules.js，否決）；(c) 裁定非債務維持現狀（Phase 4 已裁定 F1 為真實清理債，否決）。
- A：單點清理，不擠壓 W6 其他票。
- P：最可能失敗＝合併後 B1/S2 對群組選擇器解析語意不符致紅燈或漏網。防護：先讀 parseTopLevelSelectors 再動手；三態截圖比對防視覺回歸。

## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
### 合併寫法選擇（WRAP W 選項 a 落地）

採**單行群組選擇器** `.progress-bar, .progress-fill { ... }`（component-rules.js），刪除逐字重複的第二個 rule block。選擇理由：

1. **渲染語意不變**：兩 class 宣告逐字相同（height:100% / background / border-radius / transition），群組化後 computed style 完全等價；兩 class 均為 JS 活躍查詢目標（popup.js L473、popup-ui-components.js、ui-progress-handler.js），依 PM 前置驗證禁刪任一，選項 (b) 已否決。
2. **單行格式是 C1 守護的硬約束**：design-system-css-snapshot.test.js C1 以 `toContain('<selector> {')` 完整字面斷言，多行逗號換行寫法會使字面不符；與既有合併選擇器（`.progress-header, .results-header, .error-header`）格式一致。
3. 合併處保留註解說明兩 class 的 DOM 角色（容器/內層填充）與禁刪依據，防未來誤判為可刪。

### B1/S2 守護同步（設計內行為）

- `parseTopLevelSelectors` 解析語意（實作前已讀）：深度 0 掃描至 `{` 前全文、空白摺疊為單一空格——群組選擇器解析為**單一** top-level 項 `.progress-bar, .progress-fill`。
- 同步 tests/unit/helpers/popup-migrated-selectors.js：MIGRATED_SELECTORS 原兩項 `.progress-bar`、`.progress-fill` 替換為一項 `'.progress-bar, .progress-fill'`（32 → 31 條）；header 註解補「非 popup.html 原字面」例外說明。B1 全等斷言與 C1 字面斷言均由此單點同步滿足；S2（popup.html 內嵌不並存）不受影響（popup.html 內嵌 style 無此二 class）。
- design-system-css-snapshot.test.js 檔內註解「32 條」字樣未改（tests/ 變更限 helper，註解 stale 無測試影響）。
