### 實作內容

1. `manifest.json` — content_scripts.matches 與 host_permissions 新增 `*://*.kobo.com/*`
2. `src/popup/constants/bookstore-config.js` — 新增 Kobo 條目（id: kobo, url: https://www.kobo.com/tw/zh/library/books, enabled: true）
3. `src/content/platform/platform-registry.js` — 新增 Kobo PlatformConfig（hostnames: www.kobo.com / kobo.com，adapterFactory 指向 kobo-adapter）
4. `src/content/adapters/kobo-adapter.js`（新建）— 實作 PlatformAdapterInterface 17 個抽象方法：
   - isValidDomain: hostname 邊界比對 kobo.com
   - getPageType: pathname 含 /library/books 判定 library
   - getBookElements: querySelectorAll('li.item-wrapper.book')
   - parseBookElement: 解析 bookId(ebook slug)/title/author(多作者用頓號連接)/coverUrl/genre/readStatus/dateAdded(正規表達式比對)/series/readNowId(readnow UUID)
   - extractAllBooks: v1.6.0 W2 僅解析當前頁面（單頁），SSR 分頁翻頁留待 1.6.0-W3-001（已存在 blockedBy 本 ticket 的後續 ticket）

popup.js 對 BOOKSTORE_LIST 為資料驅動（無需改動即可顯示 Kobo 導航按鈕），已確認 `grep BOOKSTORE_LIST src/popup/popup.js` 讀取邏輯無需修改。
