## Problem Analysis
<!-- Schema[ANA/Problem Analysis]: 必填（.claude/pm-rules/ticket-body-schema.md） -->
### 用戶補充設計方向

多書城場景下，書目 ID 不應依賴各書城原始 ID（不同書城 ID 體系不同，可能為 null）。正確做法：

- **書目 ID**：由系統自行生成（如 UUID），作為唯一識別符
- **書城原始 ID**：作為備用欄位記錄（如 `platformBookId`），供回查書城用

### 初步根因分析

Overview `_getBookId(book)` 依賴 `book.id || book.bookId`（overview-page-controller.js:428-431）。
部分書目兩欄位皆為 falsy，導致 checkbox 不渲染（L813 `if (bookId)` 不通過）。
截圖顯示約 3/8 本書缺少 checkbox，比例不低。
