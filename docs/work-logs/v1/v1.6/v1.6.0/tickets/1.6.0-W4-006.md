## Context Bundle

### 背景

W3-005 完成後發現 UC-11/12 不在 doc CLI SSOT（`docs/app-use-cases.md`）中，CLI `doc uc list` 無法辨識。需全面盤點：

### 已知問題

1. **SSOT 檔案**：`docs/app-use-cases.md`（uc_registry.py L16）是 CLI 的唯一資料來源
2. **格式限制**：CLI 僅接受 `UC-\d{2}`（兩位數字），見 uc_registry.py L19/L38
3. **已知缺口**：UC-09/10/11/12 存在於 `docs/usecases/` 但可能未在 SSOT 註冊
4. **雙 UC 系統**：`docs/use-cases.md`（Chrome Extension v1 基線，7+N UC）與 `docs/usecases/`（獨立 UC 檔案）並存，關係未明確定義

### 審查範圍

| 檔案/目錄 | 審查重點 |
|-----------|---------|
| `docs/usecases/UC-*.md` | 每個檔案是否在 SSOT 有對應 `## UC-XX: 標題` 行 |
| `docs/app-use-cases.md` | 是否包含所有已定義 UC 的標題行 |
| `docs/use-cases.md` | Chrome Extension UC 編號是否與 usecases/ 對齊 |
| `.claude/skills/doc/doc_system/core/uc_registry.py` | regex/SSOT 路徑/豁免規則是否需調整 |

### 關鍵檔案

- `uc_registry.py:16` — `USE_CASES_SPEC_RELATIVE_PATH = "docs/app-use-cases.md"`
- `uc_registry.py:19` — `UC_HEADING_RE = re.compile(r"^## (UC-\d{2}): (.+)$")`
- `uc_registry.py:38` — `VALID_UC_FORMAT_RE = re.compile(r"^UC-\d{2}$")`
