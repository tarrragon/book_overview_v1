## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->
### 問題根因

overview-page-controller.js 有兩處硬編碼 `readmoo_books`：
1. **L510** `loadBooksFromChromeStorage()` — `chrome.storage.local.get(['readmoo_books'])` 只讀 Readmoo 書目
2. **L286** storage change listener — `changes.readmoo_books` 只監聽 Readmoo 變更

其他書城（kobo, books_com_tw 等）寫入 `{platform}_books` key 後，overview 完全看不到。

### 影響範圍

- `src/overview/overview-page-controller.js` L286, L510-514
- `src/storage/helpers/multi-platform-storage.js`（loadAllPlatformBooks 已就緒）
- `tests/unit/overview/overview-page-controller.test.js`（L474, L546 需更新斷言）

### Context Bundle

**修改策略（兩處修改 + 測試更新）**：

#### 修改點 1：loadBooksFromChromeStorage() (L507-545)
- 移除 `chrome.storage.local.get(['readmoo_books'])` 直讀
- 改用 `loadAllPlatformBooks()`（from `multi-platform-storage.js`）
- timestamp 欄位：多書城合併後不再有單一 timestamp，移除 timestamp log 或改為各書城最新 timestamp

#### 修改點 2：storage change listener (L284-301)
- 移除 `changes.readmoo_books` 硬編碼檢查
- 改為遍歷所有 `PLATFORM_IDS` 產生的 key，任一 platform key 變更即觸發 reload
- 使用 `platformBooksKey()` + `PLATFORM_IDS` 動態產生監聽 key 集

#### 修改點 3：新增 require
- 頂部新增 `const { loadAllPlatformBooks } = require('src/storage/helpers/multi-platform-storage')`
- 頂部新增 `const { PLATFORM_IDS, platformBooksKey } = require('src/background/constants/module-constants')`

#### 修改點 4：測試更新
- `tests/unit/overview/overview-page-controller.test.js` 更新斷言：不再斷言 `get(['readmoo_books'])`
- 新增多書城合併渲染測試

#### commit policy
- 單一 commit 含 src + tests，feat branch 上作業

## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
### 實作內容

1. `src/overview/overview-page-controller.js` 頂部新增 `loadAllPlatformBooks`（`src/storage/helpers/multi-platform-storage.js`）與 `PLATFORM_IDS` / `platformBooksKey`（`src/background/constants/module-constants.js`）require。
2. `loadBooksFromChromeStorage()`（原 L507-545）：移除 `chrome.storage.local.get(['readmoo_books'])` 直讀，改用 `loadAllPlatformBooks()` 取得所有書城合併書目；移除單一 `extractionTimestamp` log（多書城合併後無單一時間戳語意）。
3. storage change listener（原 L284-301）：移除 `changes.readmoo_books` 硬編碼檢查，改用 `Object.values(PLATFORM_IDS).map(platformBooksKey)` 動態產生監聽 key 集，任一 platform key 變更即呼叫 `loadAllPlatformBooks()` 重新合併並渲染（改為 async `.then/.catch`，維持原有 console.warn 後備錯誤處理）。
4. 測試更新（`tests/unit/overview/overview-page-controller.test.js`）：
   - `toHaveBeenCalledWith(['readmoo_books'])` 斷言改為動態產生的全平台 key 陣列
   - AC3 場景 1 改為驗證兩書城（readmoo + kobo）書目合併後 currentBooks/渲染表格/checkbox 數量正確
   - 新增「chrome.storage.onChanged 多書城監聽」describe block：驗證非 readmoo 書城變更觸發合併重載、非 local 區域不觸發、無 platform_books key 變更不觸發
