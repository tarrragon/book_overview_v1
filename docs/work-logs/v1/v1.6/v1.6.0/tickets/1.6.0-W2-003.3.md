## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->
### 問題根因

`tag-storage-adapter.js` 有自己的本地 `STORAGE_KEYS` 定義（L56-63），`loadBooks()`（L259）和 `saveBooksWrapper()`（L268）均 hardcode 讀寫 `READMOO_BOOKS = 'readmoo_books'`。Tag 操作只能影響 Readmoo 書目。

### 影響範圍

| 檔案 | 行號 | 問題 |
|------|------|------|
| `tag-storage-adapter.js` | 57 | 本地 `STORAGE_KEYS.READMOO_BOOKS` 定義 |
| `tag-storage-adapter.js` | 260 | `loadBooks()` 只讀 `readmoo_books` |
| `tag-storage-adapter.js` | 270, 272, 274 | `saveBooksWrapper()` 只寫 `readmoo_books` |

### 相關 Error Pattern

無直接相關 PC。

## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
### 實作內容

`src/storage/adapters/tag-storage-adapter.js`：

1. import `platformBooksKey` from `module-constants.js`
2. `loadBooks(platformId = 'readmoo')` / `saveBooksWrapper(books, platformId = 'readmoo')` 改用 `platformBooksKey(platformId)` 取代 hardcode 的 `STORAGE_KEYS.READMOO_BOOKS`
3. `withAtomicRollback` 新增第 4 參數 `platformId`，books 快照回滾走 `saveBooksWrapper(value, platformId)`
4. 全面貫穿 platformId 至所有觸碰書目的函式（皆為選填、預設 `'readmoo'`，向後相容）：`getTagsForBook`、`addTagToBook`、`removeTagFromBook`、`setBookTags`、`getBooksByTag`、`deleteTag`、`batchDeleteTags`、`checkReferentialIntegrity`、`replaceAllData`、`mergeAllData`、`deleteTagCategory`（透過 `options.platformId`，cascade 刪除影響對應書城書目）

Tag 資料（`STORAGE_KEYS.TAGS` / `TAG_CATEGORIES`）維持跨書城共用，未修改。

### 設計決策

原 Problem Analysis 僅列 loadBooks/saveBooksWrapper 兩處，但驗收條件「測試確認 tag 操作不跨書城污染」需要透過公開 API 端到端驗證。若僅改內部 loadBooks/saveBooksWrapper 而不貫穿至呼叫端（如 addTagToBook），則所有公開 API 仍會被鎖定在 readmoo，acceptance #3 無法有意義地驗證。故將 platformId 選填參數貫穿至全部觸碰書目的公開函式，預設值保持既有呼叫端零改動相容。

## Context Bundle

### 既有基礎設施

- `platformBooksKey(platformId)` — `module-constants.js:529`，已 export
- `PLATFORM_IDS` — `module-constants.js:514-520`，已 export
- `tag-storage-adapter.js` 有自己的本地 `STORAGE_KEYS`（L56-63），與 module-constants 的 `STORAGE_KEYS` 獨立

### 修改策略

**核心改法**：`loadBooks()` 和 `saveBooksWrapper()` 新增 `platformId` 參數（預設 `'readmoo'`）

1. **import** `platformBooksKey` from `module-constants.js`（統一 key 生成邏輯）
2. **`loadBooks(platformId = 'readmoo')`**（L259）：改用 `platformBooksKey(platformId)` 取代 `STORAGE_KEYS.READMOO_BOOKS`
3. **`saveBooksWrapper(books, platformId = 'readmoo')`**（L268）：同上
4. 呼叫端（tag 操作函式）需傳入 `platformId`，或維持預設（向後相容）
5. 本地 `STORAGE_KEYS.READMOO_BOOKS` 保留（其他 key 如 TAG_CATEGORIES / TAGS 不改）

### 設計決策

Tag 資料（`STORAGE_KEYS.TAGS` / `TAG_CATEGORIES`）維持跨書城共用——tag 是用戶自定義分類，不隨書城隔離。只有 books 資料按書城隔離。
