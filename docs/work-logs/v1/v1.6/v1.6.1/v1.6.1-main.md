## 版本目標

Kobo 多地區路徑支援。實測發現 Kobo 已整合為全球統一平台（www.kobo.com），
台灣站（/tw/zh/）和日本站（/jp/ja/）共用 domain、帳號、書庫，
DOM 結構完全一致，僅 aria-label 等文字隨語系變化。

主要工作：
1. bookContainer 選擇器從語系依賴改為語系無關（`[aria-label="書籍"]` → `section.library-content.book-list`）
2. platform-registry 擴展多地區路徑辨識
3. popup 書城選單新增日本站入口
4. 文件更新（bookstores/kobo.md 勘查紀錄）

## DOM 分析結論（2026-07-16 實測）

| 比較項 | 台灣站 /tw/zh/ | 日本站 /jp/ja/ |
|--------|---------------|---------------|
| domain | www.kobo.com | 相同 |
| 帳號 | 統一帳號 | 統一帳號（同一書庫） |
| 書庫容器 aria-label | "書籍" | "本" |
| 書庫容器 CSS class | library-content book-list grid | 相同 |
| 書目 CSS class | li.item-wrapper.book | 相同 |
| 其他選擇器 | 全部 CSS class-based | 全部命中 |
| 結論 | 唯一差異是 aria-label | 改用 CSS class 選擇器即可 |
