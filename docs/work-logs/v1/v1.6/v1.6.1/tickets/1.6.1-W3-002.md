## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->

### 問題根因

domain-map 對齊分析發現 messaging domain 6 個 bundle 中，Message Validation / Session Management / Connection Monitoring / Queue Management 四個 service 完全零測試覆蓋。

### 影響範圍

新增測試檔案，不修改 `src/` 產品程式碼。

### 相關 Error Pattern

無相關已知錯誤模式。

---

## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->

依 Context Bundle 不變式表，為四個 service 各建立一個 unit test 檔（`tests/unit/background/domains/messaging/`），共 9 個 test case：

- `message-validation-service.test.js`：request envelope 缺少 `type` 欄位時 `validateMessage()` 標記不合法；合法訊息通過；不合法結果的每筆 violation 皆含非空 `message`（對應 error 必填）。
- `session-management-service.test.js`：`startSession()` 後 `getSessionState()` 可查詢；`endSession()` 後查詢回傳 `null`。afterEach 清除 `sessionTimeouts` 避免殘留真實 timer。
- `connection-monitoring-service.test.js`：`performHealthCheck()` 偵測連線閒置逾時（`lastActivity` 超過 `TIMEOUTS.DEFAULT_CONNECTION_TIMEOUT`）後關閉並自 `activeConnections` 移除（對應 disconnected）；`closeConnection()` 後以相同 id 重新 `establishConnection()` 恢復 `active` 狀態（對應重連 connected）。實作未提供獨立 `disconnected`/`reconnect` 狀態機，測試以既有 `active`/`closed` 語意對應不變式描述。
- `queue-management-service.test.js`：低優先級先入隊、高優先級後入隊時，`getNextMessageBatch()` 優先取出高優先級訊息；直接填滿 NORMAL 佇列至 `QUEUE_CONFIG.MAX_QUEUE_SIZE` 後 `enqueueMessage()` 回傳 `success: false` + `Queue overflow`。

四個服務皆僅以 `new Service({ logger, eventBus })` 建構並直接呼叫業務方法，不呼叫 `initialize()`/`start()`，避免觸發 `chrome.storage`（callback-based mock）與 `setInterval` 監控迴圈的複雜性。

### 自檢結果

- 新增 4 檔純測試碼，不修改 src（Phase 4 豁免：純測試新增無重構對象）
- connection-monitoring 不變式語意對應已在 Solution 說明
- npm test 全套件 6137 tests 通過，無回歸

## Context Bundle

### 不變式（test case 規格，來源：messaging domain-map §3）

| Bundle | 不變式 |
|--------|--------|
| Message Validation | request envelope 必須含 type 欄位；response success=false 時 error 必填 |
| Session Management | session 建立後必須可查詢；銷毀後不可再查詢 |
| Connection Monitoring | 連線中斷偵測後狀態標記為 disconnected；重連後恢復 connected |
| Queue Management | 高優先級訊息優先出隊；佇列容量超限時拒絕入隊 |

### Src 檔案

- `src/background/domains/messaging/services/connection-monitoring-service.js`
- `src/background/domains/messaging/services/queue-management-service.js`
