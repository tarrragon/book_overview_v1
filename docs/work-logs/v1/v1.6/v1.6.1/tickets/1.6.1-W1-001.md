## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->
### 問題

kobo-adapter.js L61 的 `bookContainer` 選擇器使用 `[aria-label="書籍"]`，
這是台灣站的中文 aria-label。日本站（/jp/ja/）的 aria-label 為「本」，
導致 `findBookContainer()` 和 `checkPageReady()` 在日本站無法命中。

### 實測證據（2026-07-16）

| 選擇器 | 台灣站命中 | 日本站命中 |
|--------|-----------|-----------|
| `[aria-label="書籍"]` | 1 | 0 |
| `section.library-content.book-list` | 1 | 1 |
| 其他所有 CSS class 選擇器 | 全部命中 | 全部命中 |

### 修改方案

將 `SELECTORS.bookContainer` 從 `'[aria-label="書籍"]'` 改為 `'section.library-content.book-list'`。
影響範圍：僅 L61 一行常數，`findBookContainer()` (L223) 和 `getLoginCheckSelector()` (L157) 透過 SELECTORS 間接引用。

## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
將 `src/content/adapters/kobo-adapter.js` L61 的 `SELECTORS.bookContainer` 由
`'[aria-label="書籍"]'`（僅命中台灣站）改為 `'section.library-content.book-list'`
（語系無關 CSS class 組合，台灣/日本站皆命中）。

同步更新：
- fileheader `@fileoverview` 中「Kobo 台灣站書庫頁」移除地區限定字樣，改為「Kobo 書庫頁」（純註解，無邏輯影響）
- `tests/unit/adapters/kobo-adapter-pagination.test.js` 4 處 mock HTML 的 `<region aria-label="書籍">`
  改為 `<section class="library-content book-list">`，對齊 docs/bookstores/kobo.md 實測 DOM 結構

驗證：node -e 以 jsdom 分別建構 `aria-label="書籍"`（台灣）與 `aria-label="本"`（日本）的
`section.library-content.book-list` 元素，確認新選擇器對兩者皆命中（TW match: true / JP match: true）。
