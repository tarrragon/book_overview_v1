# Execution Log

## Task Summary

extraction domain 四個 service require ErrorCodes 方式錯誤（直接拿 module.exports 非解構 .ErrorCodes），導致 error.code/details 為 undefined

---

## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->

### 問題根因

`const ErrorCodes = require('.../core/errors/ErrorCodes')` 取得整個 module.exports 物件（`{ ErrorCodes }`），未解構出 `ErrorCodes` 本身，導致後續 `ErrorCodes.VALIDATION_ERROR` 等存取回傳 `undefined`，使 `error.code` / `error.details` 皆為 `undefined`。

### 影響範圍

以 `rg "const ErrorCodes = require.*ErrorCodes" src/background/domains/ --files-with-matches` 重新確認完整清單，實際受影響為 21 個檔案（多於 ticket 原描述的 13 個，多出 messaging domain 6 個檔案 + user-experience/extraction 各多 1 個）：

- extraction/services：export-service.js、quality-control-service.js、validation-service.js、data-processing-service.js、extraction-state-service.js（5 個）
- messaging：messaging-domain-coordinator.js、message-routing-service.js、message-validation-service.js、connection-monitoring-service.js、session-management-service.js、queue-management-service.js（6 個，原 ticket where.files 未列，依規則 3 一併修復）
- user-experience：theme-management-service.js、accessibility-service.js、preference-service.js、notification-service.js、ux-domain-coordinator.js、popup-ui-coordination-service.js（6 個）
- platform/services：platform-switcher-service.js、platform-registry-service.js、platform-isolation-service.js、adapter-factory-service.js（4 個）

### 相關 Error Pattern

W3-001 SR-1 首次發現（跨檔案 bug），W3-004 SR-3 擴大範圍，本 ticket 為修復。

---

## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->

以 `sed -E "s/const ErrorCodes = require\(/const { ErrorCodes } = require(/"` 對上述 21 個檔案批次修正，將 `const ErrorCodes = require(...)` 改為 `const { ErrorCodes } = require(...)`（require 路徑本身不動）。修復後執行 `rg "const ErrorCodes = require.*ErrorCodes" src/background/domains/ --files-with-matches` 確認無殘留（空輸出）。

## Context Bundle

### Bug 描述

`const ErrorCodes = require('../../core/errors/ErrorCodes')` 取整個 module.exports（`{ ErrorCodes }`），未解構。應改為 `const { ErrorCodes } = require('../../core/errors/ErrorCodes')`。導致所有 `error.code = ErrorCodes.VALIDATION_ERROR` 賦值為 undefined。

### 受影響檔案（用 grep 確認完整清單）


### 修復方式

`const ErrorCodes = require(...)` → `const { ErrorCodes } = require(...)`

### 驗證

修復後 grep 確認無殘留 + npm test 通過 + 抽查 error.code 不為 undefined。
